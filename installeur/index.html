This system is not Windows, and the DeskNode agent is.
The flash below will work — the browser's serial access exists on macOS, Linux and ChromeOS too — but the agent that feeds the panel its readings only exists on Windows. You would put a correct firmware on a board with nothing to display: the panel would start, and stay empty. That is a declared gap of this project, ⛔ not a defect of this page — and you are told now rather than afterwards. Ce système n'est pas Windows, et l'agent DeskNode l'est.

Vous poseriez donc un firmware correct sur une carte qui n'aurait rien à afficher : la dalle démarrerait, et resterait sans données. C'est un écart déclaré du projet, ⛔ pas un défaut de cette page — et il vous est dit maintenant plutôt qu'après.

  1. Stop the DeskNode agent. It is what holds the serial port. Arrêter l'agent DeskNode. C'est lui qui tient le port série.

    The DeskNode agent is installed on this machine — it holds the port while it runs.
    ⚠️ What is measured here is that the scheduled task exists: this page queries the task scheduler, it opens no port, and it therefore cannot claim the agent is running right now. This is the normal second-launch case: updating DeskNode means reinstalling it, and the agent is already running. If the port is held and you flash, the browser will fail on Failed to execute 'open' on 'SerialPort' — a message that explains nothing. The button above frees the port by calling the stop verb this repository already ships, on the port actually discovered; if nothing held it, it will say that too.     L'agent DeskNode est installé sur cette machine — il tient le port quand il tourne.
    ⚠️ Ce qui est mesuré ici, c'est que la tâche planifiée existe : cette page interroge le planificateur de tâches, elle n'ouvre aucun port et ne peut donc pas affirmer que l'agent tourne en ce moment. C'est le cas normal du deuxième lancement : mettre DeskNode à jour, c'est le réinstaller, et l'agent tourne déjà. Si le port est tenu et que vous flashez, le navigateur sortira sur Failed to execute 'open' on 'SerialPort' — un message qui n'explique rien. Le bouton ci-dessus libère le port en appelant le verbe stop que le dépôt livre déjà, sur le port réellement découvert ; si rien ne le tenait, il vous le dira aussi.

    That dialog belongs to the flashing tool, ⛔ not to DeskNode. The repository already says so : "No driver to install, neither on Windows nor on Linux."
    If the port does not appear, it is not a missing driver — it is one of the cases named just above.     Ce dialogue est celui de l'outil de flash, ⛔ pas de DeskNode. Le dépôt le dit déjà : « Aucun pilote à installer, ni côté Windows ni côté Linux. »

        What these two verbs are, and why neither needs administrator rights
        Ce que sont ces deux verbes, et pourquoi aucun ne demande de droits administrateur
      
      

        This page invents nothing : it calls the stop and
          retirer verbs of the tool the repository already ships, and hands you
          their output as it is, exit code included. Neither asks for administrator
          rights, and neither needs them.
          Removing drops the scheduled task, then asks the system for it again: it
          is that second question that decides, ⛔ not the message of the first.
        Cette page n'invente rien : elle appelle les verbes
          stop et retirer de l'outil que le dépôt livre déjà, et elle
          vous rend sa sortie telle quelle, code de retour compris. Aucun des deux ne
          demande de droits administrateur, et aucun n'en a besoin.
          Retirer dépose la tâche planifiée, puis la redemande au système :
          c'est cette seconde question qui décide, ⛔ pas le message de la première.
