Ce système n'est pas Windows, et l'agent DeskNode l'est.
Le flash ci-dessous marchera — l'accès série du navigateur existe aussi sur macOS, Linux et ChromeOS — mais l'agent qui alimente la dalle en grandeurs n'existe que sous Windows. Vous poseriez donc un firmware correct sur une carte qui n'aurait rien à afficher : la dalle démarrerait, et resterait sans données. C'est un écart déclaré du projet, ⛔ pas un défaut de cette page — et il vous est dit maintenant plutôt qu'après.
Le module de flash n'a pas pu être chargé.
Le bouton d'installation est chargé depuis unpkg.com — c'est le seul morceau de cette page qui vient d'Internet, et il est épinglé à une version exacte. Si vous êtes hors ligne, ou si un pare-feu bloque ce domaine, il n'arrive pas. Le geste : rétablir l'accès à unpkg.com, puis recharger cette page. ⛔ Il n'y a pas de bouton inerte à cliquer : cet encadré remplace le bouton, plutôt que de vous laisser deviner.
L'agent DeskNode tient déjà le port de la carte.
C'est le cas normal du deuxième lancement : mettre DeskNode à jour, c'est le réinstaller, et l'agent tourne déjà. Si vous flashez maintenant, le navigateur sortira sur Failed to execute 'open' on 'SerialPort' — un message qui n'explique rien. Le bouton ci-dessous libère le port en appelant le verbe stop que le dépôt livre déjà, sur le port réellement découvert.

Ce dialogue est celui de l'outil de flash, ⛔ pas de DeskNode, et il parle d'un problème que vous n'avez pas. Cette carte est en USB natif (303A:1001, série/JTAG intégré à la puce) : Windows la reconnaît avec son pilote usbser d'origine, et aucun pilote tiers n'est à installer, ni ici ni ailleurs. Le dépôt le dit déjà : « Aucun pilote à installer, ni côté Windows ni côté Linux. »
Si le port n'apparaît pas, ce n'est pas un pilote qui manque — c'est un des trois cas juste en dessous.

Ce que vous allez voir, et ce qu'il faut faire

1. Le nom du port — ⛔ il ne s'appelle PAS « DeskNode ».

  • Windows l'affiche sous un nom traduit : en français, Périphérique série USB (COM3) — le numéro change d'une machine à l'autre. Mesuré sur la machine de référence le 2026-09-08.
  • La puce, elle, se présente comme USB JTAG/serial debug unit : c'est cette chaîne-là que certains navigateurs affichent, seule ou suivie du (COMn).
  • ⚠️ Les deux formes désignent la même carte. Ce que le sélecteur de votre navigateur montre exactement n'est pas mesuré ici : prenez la ligne qui porte l'une des deux — et, en cas de doute, celle dont le (COMn) est celui affiché en haut de cette section.

2. La sélection se fait en DEUX gestes.

  • Cliquer la ligne du port pour la sélectionner ;
  • puis cliquer « Se connecter ».
  • ⛔ Tant que la ligne n'est pas sélectionnée, « Se connecter » reste grisé, et fermer la fenêtre fait sortir sur « No port selected » — un message qui n'explique pas qu'il manquait un clic.

3. Si la carte ne répond pas du tout : la récupération.

  • Le geste écrit et mesuré dans ce dépôt est : maintenir le bouton BOOT enfoncé, appuyer brièvement sur RESET, puis relâcher BOOT. La carte passe en mode download, où le flash fonctionne même quand l'application ne démarre plus.
  • ⚠️ Écart déclaré, écrit plutôt que recopié : le cadrage de cette page parlait de « BOOT maintenu pendant le branchement ». Cette formule-là n'est écrite nulle part dans le dépôt et n'a jamais été mesurée ; c'est BOOT + RESET qui l'est. La page écrit donc ce qui est vrai, ⛔ pas ce qui était supposé.
  • ⚠️ Une fois en mode download, la carte n'en ressort pas par la fin de flash ordinaire : appuyez sur RESET pour la relancer.

D'où vient ce que vous installez. Le manifeste annonce une version qui est lue dans le binaire lui-même (esp_app_desc_t), ⛔ jamais recopiée à côté : c'est la révision exacte du dépôt qui l'a produite, et une vérification mécanique du dépôt refuse qu'elles diffèrent. Le firmware est sous GPL-3.0-or-later, ce qui oblige à pointer la source de cette révision précise — pas « le dépôt » en général : c'est charge/PROVENANCE.md qui la nomme, avec les empreintes des quatre morceaux et la commande qui les a produits. ⚠️ Et ce qui manque y est écrit aussi : aucune intégration continue ne construit ce firmware, ces binaires ont été faits à la main, et il n'existe ni tag ni release — donc pas encore de source publiquement atteignable. Les deux manques ont un porteur nommé, dans ce fichier.
