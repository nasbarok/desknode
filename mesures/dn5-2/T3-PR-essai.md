# Branche d'essai — `dn5-2` / AC2.4

Cette branche n'existe que pour **exercer le workflow CLA sur une pull request
interne**, et relever ce qu'il fait réellement : le run existe-t-il, quel est son
`conclusion`, le bot poste-t-il son commentaire, le magasin de signatures est-il créé.

⛔ **Elle n'est pas destinée à être fusionnée.** La PR est ouverte, observée, puis
**fermée**. Le relevé part dans `mesures/dn5-2/T3-essai-cla.txt`.

⚠️ Sur un dépôt **privé, 0 fork, 1 collaborateur**, aucun contributeur **externe** ne
peut ouvrir de PR. Ce que cet essai mesure est donc borné, et la preuve d'exécution sur
une PR externe est portée par `dn8`.
