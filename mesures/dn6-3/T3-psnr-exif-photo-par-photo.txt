=== (3) 🔴 CE QUE LE REMPLACEMENT A FAILLI EMPORTER : LE MODE DU FICHIER ====
  MESURE, ⛔ pas suppose : les 11 candidates sont suivies en `100755` dans
  l'index (13 des 20 le sont). Ecrire le candidat dans un `mkstemp` puis
  `os.replace` lui donne le mode du TEMPORAIRE (0600) ⇒ `git diff --summary`
  annoncait **11 `mode change 100755 => 100644`** — un changement que
  ⛔ PERSONNE n'avait demande, invisible dans un `git diff --stat` qui ne
  montre que « Bin ».
  ⇒ les modes d'origine ont ete RESTAURES. Etat final :
       `git diff --summary docs/cablage/` : 0 ligne `mode change`
       `git diff --stat    docs/cablage/` : 11 files changed, 0 insertions, 0 deletions
  ⚠️ Le mode n'est ⛔ pas un detail de presentation : c'est le seul champ que
     git garde a cote du contenu, et un `chmod` de masse « pour normaliser »
     l'aurait grave dans l'historique — que `NFR1` interdit de reecrire.
