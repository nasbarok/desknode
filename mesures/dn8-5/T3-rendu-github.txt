   prescrivait `gh api -X POST /markdown -f mode=gfm …` et d'y relever les
   `id="user-content-…"`. MESURE : `mode=gfm` N'EMET AUCUNE ANCRE (§ 0, 0 id sur
   les quatre fichiers) — c'est le rendu d'un COMMENTAIRE. Le rendu d'une PAGE
   de fichier est `mode=markdown`, qui pose `<a id="user-content-…"
   class="anchor">` ; et ce format est RECOUPE par l'API contents
   (`Accept: application/vnd.github.html`) sur la version deja poussee de
   `CONTRIBUTING.md`, qui rend les memes ancres. ⇒ le tir de `gfm` est GARDE
   (§ 0), et les ancres sont relevees en `mode=markdown` (§ 1).
