  ✅ `charge/manifest.json` est **REELLEMENT DEMANDE AU SERVEUR** — c'est la
     moitie d'`AC7.2.1` qui se prouve sans main.
  🔴 **ET UNE ATTENTE A ETE REFUTEE ICI, ELLE EST ECRITE PLUTOT QUE TUE** : la
     1re redaction de cette sonde annoncait « le module de flash le demande
     AUSSI ». **C'est FAUX, et le compte le dit** : le manifeste est demande
     **UNE** fois, par le script de la page. ESP Web Tools ne le lit **qu'au
     CLIC** sur le bouton d'installation — ce qui appartient a la moitie qui
     exige une main, ⛔ pas a celle-ci. ⇒ la phrase fausse est remplacee par le
     compte mesure.

── LA LISTE BLANCHE TIENT, ET ELLE A ETE EPROUVEE EN CHEMINS **BRUTS** ─────

🔴 UNE PREMIERE MESURE A CONCLU « SERVI : HTTP 200 » SUR `/charge/../README.md`,
   ET ELLE MESURAIT LE **CLIENT**, ⛔ PAS LE SERVEUR : le client HTTP NORMALISE
   le chemin avant de l'emettre, et envoie `/README.md` — qui est servi
   DELIBEREMENT depuis `dn7-1` (les liens du pied de page). ⇒ rejoue en socket
   nu, chemins emis TELS QUELS :

    /charge/desknode.bin                   -> HTTP/1.0 200 OK          corps=1266752 o
    /charge/../README.md                   -> HTTP/1.0 404 Not Found   corps=47 o
    /charge/../../etc/passwd               -> HTTP/1.0 404 Not Found   corps=51 o
    /charge/..%2fREADME.md                 -> HTTP/1.0 404 Not Found   corps=49 o
    /installeur/dn_installeur.py           -> HTTP/1.0 404 Not Found   corps=55 o
    /charge/                               -> HTTP/1.0 404 Not Found   corps=35 o

  ⇒ la liste blanche est une LISTE, ⛔ pas un prefixe : rien ne se deduit d'un
    chemin, tout se compare a une entree ECRITE.
